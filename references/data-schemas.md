# Schémas de données

- `data/steps.json` : champs déduits de check-steps.py (id, t, dur, cam, type, kw). Lu/écrit par check-steps.py.
- `data/figures.json` : registre des chiffres. Lu par build_studio_*.
- `data/design.json` : paramètres de design. Lu par build.
- `data/refs.json` : registre des références `Rxx` (tweet, page, capture, video, image). Lu par la composition.
